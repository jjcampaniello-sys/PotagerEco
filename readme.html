🌱 Mon Potager en Lasagne

Documentation du projet

Fonctionnalités

  • Carrés adaptatifs : grille dynamique (2×2 à 5×5) selon les dimensions réelles et l'espacement optimal des plantes.
  • Catalogue de plantes : 25+ plantes avec semis, repiquage, vulnérabilités, associations — extensible, classé par menu déroulant.
  • Assistant de plantation : ensoleillement, espacement minimal, associations bénéfiques/incompatibles (enrichissables depuis l'interface).
  • Calendrier de récolte : estimation par degrés-jours de croissance (GDD), propre à chaque plante et sa météo réelle.
  • Météo à 3 jours : températures, pluie, humidité, vent, bandeau d'alerte anticipée, recommandations personnalisées.
  • Zone climatique : ajustement automatique selon la latitude détectée.

Stockage

Toutes les données sont sauvegardées dans le localStorage du navigateur — aucun serveur, aucune donnée envoyée ailleurs que vers l'API météo Open-Meteo (position GPS uniquement).

Fichiers

  • index.html — structure de la page
  • app.js — logique complète de l'application
  • style.css — mise en forme
